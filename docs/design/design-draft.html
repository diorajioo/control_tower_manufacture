Known Issues & Technical Debt
As of 2026-09-28 · Control Tower Manufacturing · Why Framework applied to each issue
Critical
1. Lead Time Page: Static Mock Data (Tactical, Operational, Monitor)
Partially Resolved Area: /lead-time Tactical/Operational · LeadTimeMonitor.tsx
Stage breakdown, VA/NNVA/UNVA charts, batch exception heatmap still use hardcoded data. Strategic KPI cards use real Snowflake data.
Why it exists
Strategic KPI cards were prioritized first — Plant Managers use Strategic view daily. Tactical/Operational require a more complex query pattern (position-level breakdown with VA/NNVA categorization per PO). Schema design for CT_MANUF_LEADTIME was validated through Strategic before investing in the more expensive per-position queries.
Impact: Users on Tactical/Operational view see outdated representative data, not real plant state.
Fix path: New query getLeadTimeByPositionCategory() → new endpoint /api/lead-time/tactical → replace hardcoded constants.
Medium
2. Azure AD Plant-Level Access Control Not Implemented
Planned Area: Authentication · API routes
Any authenticated user can query any plant via the filter. No data isolation between plants.
Why it exists
Azure AD group provisioning requires IT Admin consent + group setup coordination across HR/IT. The user base is currently small and all from trusted Paracorp staff, so the security risk is accepted. Adding RBAC at the API layer requires group-membership claims in the JWT token, which needs admin-level Azure app registration changes.
Impact: A Plant 1 manager can see Plant 2 data.
Fix path: Add allowedPlants claim to Azure AD app → read from NextAuth session → filter in API route middleware.
Low
3. KPI Cache Not Shared Across Vercel Edge Nodes
Known Limitation Area: /api/dashboard/kpi · /api/dashboard/trends
unstable_cache is in-memory per Vercel instance. Two users on different nodes may see different cache generations within the same 1-hour window.
Why it exists
Next.js unstable_cache was chosen for zero-infrastructure simplicity (no Redis, no extra cost). Vercel's distributed deployment model means each cold-start gets its own cache. Acceptable trade-off given a 1-hour TTL and low concurrent user count.
Impact: Minor data inconsistency — negligible for this use case.
Fix path: Add a Redis/Upstash adapter or upgrade to Vercel KV if consistency becomes critical.
4. Lato Font Has No Weight 500 or 600
Known Constraint Area: Typography system-wide
Tailwind font-medium (500) and font-semibold (600) silently fall back to 400 or 700.
Why it exists
Lato was mandated by the Paracorp brand design system (Paradise v2). Lato only ships in 400 and 700. No middle-weight variant exists in the Lato family.
Impact: Some text appears lighter than intended when font-medium / font-semibold classes are used by habit.
Fix path: Lint rule to flag font-medium/font-semibold in this codebase. Use font-normal (400) or font-bold (700) only.
5. Placeholder Pages With Dead Nav Links
Planned Area: Sidebar navigation
Alert Center · Output · Productivity · Yield · Energy · OEE · Root Cause Analysis · Reports · AI Fusion · User Management are shown in sidebar but have no pages.
Why it exists
Nav items were included at initial build to communicate the product roadmap to stakeholders. Building all pages simultaneously wasn't feasible — core pages (Overview, Lead Time) were prioritized. The dead links were later converted to no-ops (no 404 anymore) but the pages don't exist yet.
Impact: Users see planned features but can't access them.
Fix path: Build each page incrementally. KPI data for Output/OEE/Yield is already available from existing Snowflake queries.
6. E2E Productivity: No Prior-Period Trend for YTD
Open — Data Limitation Area: Overview E2E Productivity KPI card
Card shows value with "No Prior Data" status for YTD filter. CT_MANUF_E2E table only has 2026 data.
Why it exists
YTD's prior period is Jan–Sep 2025, which doesn't exist in the table. delta() returns null → card shows "No Prior Data". Will resolve automatically once the table has data spanning at least two comparable periods.
Impact: No trend signal on E2E Productivity for YTD — only shorter windows (30D/90D) show a delta.
Fix path: None required — resolves passively as data accumulates, OR backfill 2025 data if available.
7. Lead Time Monitor Uses Different Card Style (Intentional)
Intentional Design Divergence Area: StrategicMonitor.tsx · LeadTimeMonitor.tsx
Monitor components use rounded-xl border-slate-200, dashboard uses rounded-lg border-[#EBEBEB].
Why it exists
Monitor was built for a fullscreen, high-density display context (large TV/screen). rounded-xl gives a bolder visual at distance; rounded-lg suits desktop dashboard density. Both are correct for their context.
Impact: None — intentional.
Fix path: No fix needed. Document as a design decision.
Doc Drift (Low)
8. PRODUCT.md and DESIGN.md Describe Outdated Features
Open — Documentation Drift
PRODUCT.md still references Monitor Mode with auto-rotating TV mode and old AI model names. DESIGN.md describes the old 2-col/3-col Strategic/Tactical equipment layout.
Why it exists
These files were generated by the Impeccable AI skill at an early project stage and treated as living docs. As features were removed/changed in code, these docs weren't updated because (a) they're Impeccable artifacts not meant for manual editing, and (b) the docs/ directory was established as the authoritative layer instead.
Impact: Low — only affects new developers reading stale artifacts.
Fix path: Treat PRODUCT.md and DESIGN.md as historical context only. All authoritative documentation lives in docs/.
