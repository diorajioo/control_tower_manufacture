## Anti-Slop Rules
<!-- antislop:start -->
Untuk semua pekerjaan UI/design di project ini, baca dan ikuti rules berikut:
- Core rules: `.claude/skills/antislop/antislop.md`
- UI depth: `.claude/skills/antislop/antislop-ui.md`
- Copywriting: `.claude/skills/antislop/antislop-copywriting.md`

Sebelum mulai pekerjaan UI apapun:
1. Baca core rules antislop.md
2. Tanya user: antislop berlaku SELAMA pengerjaan atau SETELAH selesai?
3. Jangan mulai sampai user menjawab.

Jangan ubah layout yang sudah ada atau kalkulasi KPI kecuali diminta eksplisit.
